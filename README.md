## How to run
* Open Visual Studio Code
* Go to Terminal Menu, Select New Terminal
* In Terminal window, from dropdown, select Command Prompt
![alt text](Terminal.png)

* Execute below command in terminal to create a virtual environment (create in parent folder of the assignment).

```bash
python -m venv python_venv #to create venv

python_venv\Scripts\activate #to activate venv
```

 * Execute below command in terminal to install seaborn in assignments folder

```bash
pip install pandas
pip install nltk
pip install scikit-learn
pip install streamlit

```
